Look at erosion.py for a general idea of how the erosion pipeline should work. Then, use the textures and resources initialized in terrain.rs to roughly re-create this pipeline using the gpu shaders in the shaders directory. It should execute shader passes to handle rain/evaporation first, then erosion, then advection. Look at the shaders to see which textures need to be bound where. If you would need to refactor something related to shaders or initialization of gpu resources, or if something seems set up incorrectly, ask me before proceeding.
The accumulate shader accumulates water and handles evaporation. The "sobel" shader does a lot of things, it finds the sobel gradients (which represent velocity), handles thermal erosion, handles hydraulic erosion and sediment deposition. Then the advection shader simply advects the water and sediment along the velocity vector.
